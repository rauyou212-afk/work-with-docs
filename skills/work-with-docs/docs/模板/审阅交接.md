# 审阅交接提示

[文档目录](../00目录.md) · [审阅规则](../工作规则/W03-文档审阅.md) · [核验与交付](../工作规则/W05-正式落文与记录.md)

用户或适用项目规则明确需要额外交接时使用；普通审阅在聊天交代结果和入口即可。

交接只保留接手者实际需要的信息：

- 权威产物入口与本次结果；入口按 [W01](../工作规则/W01-文档组织与链接.md#库内与库外链接)适配接手者的阅读环境。
- 尚需承接的问题或工作，已登记的引用唯一待讨论或任务位置；其余简述，不为交接自动登记，写入清单按 W04 取得用户授权。
- 会影响接手判断的权限、基线或核验限制，确有必要才说明。

已有原稿、发出稿和专业证据只链接，不抄全文或重复执行过程。未确认内容不能写成有效规则；指定格式有额外要求时，在该交接材料中按需提供。
