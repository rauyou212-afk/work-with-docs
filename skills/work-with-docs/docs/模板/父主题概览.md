# 父主题概览模板

[文档目录](../00目录.md) · [组织规则](../工作规则/W01-文档组织与链接.md) · [叶子词条](独立词条.md)

在“编号＋父主题名称”文件夹内保存 `00概览.md`；标题保留父主题完整编号与名称。顶部链接总目录，有上级主题时链接上一级。

按 [W08](../工作规则/W08-写作与表达.md#先建立整体认识再展开细节)组织阅读：首段摘要帮助判断是否继续；随后用适合主题的形式说明主要组成、作用和关系；需要深入时再进入细节或子页。篇幅与适用要求以 W08 为准，成品使用自然的主题标题，不把这三个层次套成固定栏目。

下面演示“短摘要＋关系说明＋子目录”。假设本地保存、导出和导入的规则已确认；示例内容与文件名须替换为本次真实资料。

```markdown
# F01 · 资料怎样保存和转移

[总目录](../../00目录.md) · [上一级](../00概览.md)

资料保存在当前设备，换设备时需要通过文件转移。日常使用依靠[本地保存](F01.1-本地保存.md)，保留额外副本则先[导出](F01.2-导出副本.md)，需要恢复或转移时再[导入](F01.3-导入副本.md)。本主题说明三者的分工和使用条件。

## 三种操作怎样配合

可以把资料流转看成“正在使用的资料”和“另存的副本”之间的往来。本地保存更新当前设备上的资料；导出把选定内容制成文件，供另外保管或传递；导入读取已有文件，核对后把内容放回当前设备。三者分别处理日常更新、保留副本和重新使用副本，具体覆盖范围及冲突处理见各自正文。

## 按需要深入

- [F01.1 本地保存](F01.1-本地保存.md)：日常修改何时生效，失败后怎样继续。
- [F01.2 导出副本](F01.2-导出副本.md)：文件包含哪些资料，以及适合何时导出。
- [F01.3 导入副本](F01.3-导入副本.md)：怎样核对文件并处理已有内容。
```

组成适合比较时可用小简表代替部分解释；需要说明协作关系时可选简单示意或一个贴切例子。按本篇需要选择，摘要、整体说明和目录各自提供有用信息，详细规则由子页承载。

子目录逐项链接独立文件：叶子主题指向“编号＋名称.md”，继续拆分的子主题指向其文件夹内的 `00概览.md`。总目录也应能沿层级直接定位这些主题。

父页与子页都只写值得长期保存的确认结果及必要解释；未完成事项按 W04 优先在本轮处理，经用户授权留待后续的才写入待讨论，草案与临时方案按需放入工作材料。模板说明不进入成品。
