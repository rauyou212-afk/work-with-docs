# 目录页模板

[文档目录](../00目录.md) · [组织规则](../工作规则/W01-文档组织与链接.md)

总目录默认命名 `00目录.md`，用标题分类、嵌套列表呈现主题层级。每个正式主题节点链接独立文件，父主题链接其目录内的 `00概览.md`。以下为结构示例：

```markdown
# 文档集合名称

用简短文字说明适用范围。

## 流程

- [F01 项目探索与定位](流程/F01-项目探索与定位/00概览.md)
  - [F01.1 理解问题与使用场景](流程/F01-项目探索与定位/F01.1-理解问题与使用场景.md)
  - [F01.2 查明事实与关键风险](流程/F01-项目探索与定位/F01.2-查明事实与关键风险.md)
  - [F01.3 收敛目标与探索路径](流程/F01-项目探索与定位/F01.3-收敛目标与探索路径.md)

## 辅助入口

- [待讨论](待讨论.md)
- [工作材料](工作材料/)
- [历史归档](归档/)
```

只保留已存在且有用途的入口，并替换为实际路径；项目另有归档位置时沿用，不为套模板创建目录。历史材料通过必要归档入口查找，不逐项混入当前主题目录。按需结果记录沿用项目要求，不预设每日记录入口。

目录用于查找内容，可以补充用途说明，不复制正文、待办详情或默认维护完成状态。术语查找由一个入口承担；已有术语父文档时直接链接其概览。

日常修订同步受影响入口；用户发起归档后，按 W06 在本次整理范围内重新编号并更新当前引用，历史归档不改。模板说明不进入成品。
