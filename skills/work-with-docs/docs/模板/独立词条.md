# 独立词条模板

[文档目录](../00目录.md) · [组织规则](../工作规则/W01-文档组织与链接.md)

用于叶子主题：文件名为“编号＋名称.md”，标题保留完整编号与主题名称；顶部链接实际总目录和上一级。若有能独立查找、引用、审阅和维护的子主题，先拆为独立文件，父页使用[父主题概览](父主题概览.md)。

简单主题用一句话定位后直接解释即可。内部有多个需理解其关系的部分时，按 [W08](../工作规则/W08-写作与表达.md#先建立整体认识再展开细节)先给摘要，再建立本篇整体认识，最后进入细节。背景承接上一级，具体形式及标题按内容选择；长度和检查要求统一由 W08 维护。

下面以同一项“导入”操作示范。假设示例行为已确认，实际生成时替换为有效规则和链接；三个操作环节是本主题内部的步骤。

```markdown
# F01.3 · 导入副本

[总目录](../../00目录.md) · [上一级](00概览.md)

导入用于在当前设备重新使用已有副本。应用会先读取并核对文件，列出能导入的内容及冲突，再按你确认的选择写入资料。需要恢复或转移数据时，可在这里查看各环节的做法和失败处理。

## 从文件到可用资料

一次导入分为读取、核对和写入三个相连的环节：读取识别文件里的内容，核对判断哪些内容能使用、与已有资料有何冲突，写入才把确认的结果保存到当前设备。前面的环节为后面的操作提供依据；找到文件或成功读取，并不代表资料已经导入完成。具体结果和失败后的处理见下面各节。

## 读取文件

选择已有副本后，应用读取其中内容并检查文件是否能识别。不能识别时显示原因，当前资料保持原样。

## 核对内容和冲突

阅读可导入内容与冲突说明，按既定选项决定怎样处理；选择完成后确认写入。

## 写入并确认结果

应用保存确认的内容，报告实际写入结果。写入失败时按错误提示继续处理，以实际结果判断是否完成。
```

正文保存当前有效的定义、规则、长期方案或有依据的事实，以及理解和使用所需的理由、条件、关系和示例。必要关联按 [W01](../工作规则/W01-文档组织与链接.md#库内与库外链接)区分库内路径与库外打开方式。摘要中的结论、整体说明中的关系应能在详细正文找到支持。

正文准入与事实表达按 W05。方案尚未实施或验证时如实说明；临时草稿和研究过程按 W04 保存。术语定义由唯一入口索引，详细操作和业务规则仍留在对应正文。普通步骤、例子和局部小标题留在本主题，不按句子拆分。

尚需决定、核实或落实的事项先按 W04 在本轮处理；需要留待后续并获用户授权时才写入待讨论，已有任务则引用其入口。正文只保留理解和使用当前内容需要的信息，不默认另建 ISSUE 或完成状态。

按用途取用内容，不为填模板堆字段；模板说明和本页导航不进入成品。
