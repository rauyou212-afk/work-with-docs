# 待讨论清单模板

[文档目录](../00目录.md) · [维护规则](../工作规则/W04-会议与阶段总结.md)

仅在用户授权收录后续事项时使用，具体写入与维护条件见 W04。本轮对话能完成的事项直接处理，不先登记。每库按需一份 `待讨论.md`，已有同用途清单时复用；有获准事项再创建。按主题组织工作，写清问题或动作及必要背景、完成条件和资料入口。以下假设用户已同意将示例事项留待后续并收录，标签和字段按实际用途取用：

```markdown
# 待讨论

[返回总目录](00目录.md)

## 使用手册

- 待确认：新成员需要独立的快速上手版，还是沿用完整手册？方案比较见工作材料中的上手说明草稿。
- 待办：将已确认的恢复步骤补入操作说明，并检查步骤和链接是否可用。
```

在授权维护范围内，已收录事项讨论解决但尚需落文或执行时，改写为剩余待办；相关工作完成并核对后删除条目，明确取消的事项也移除。暂缓事项保留并简短写明恢复条件。清单不保存完成过程、结案说明或历史档案，方案比较与研究经过放在工作材料中。

已有任务系统时只放必要入口，详情和状态沿用原系统。清理条目时同步当前引用和空主题；清空后可保留原文件和入口，不填“暂无问题”等占位。生成时替换真实导航和事项，不保留示例及模板说明。
