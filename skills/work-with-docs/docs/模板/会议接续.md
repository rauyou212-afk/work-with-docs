# 按需结果简记模板

[文档目录](../00目录.md) · [记录规则](../工作规则/W05-正式落文与记录.md)

仅在用户需要回顾记录或项目有记录要求时使用。沿用已有位置、格式和周期；没有位置约定时可放在 `工作材料/`，按用途命名并复用同用途文件，不默认按日生成。以下为写法示例，不代表待写文档的实际决定：

```markdown
# 使用手册 · 结果简记

新成员沿用完整手册，在首页增加快速上手入口，按准备、操作和恢复顺序阅读。本次补充恢复步骤，详细内容见对应操作说明。
```

用于执行结果简记时，按 [W08 的报告型写法](../工作规则/W08-写作与表达.md#按文档类型安排开头与正文)先写结论、意义和重要问题，再按需说明执行内容。概括具体决定、有意义的内容变化和影响含义的必要条件，提供真实正文链接。按内容选段落或短列表，不设置必填的讨论、结果、变更栏目，也不复写正文或执行过程。

已登记的未完成事项只链接唯一待讨论或任务位置；其余在聊天说明，是否收录按 W04 取得用户授权。未确认内容按 W04 处理；表达按 W08 让读者理解结果，再删去重复。模板说明不进入成品。
