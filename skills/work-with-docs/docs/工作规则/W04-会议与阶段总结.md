# W04 · 会议与阶段总结

[文档目录](../00目录.md) · [上一词条](W03-文档审阅.md) · [下一词条](W05-正式落文与记录.md)

## 用户主持的会议

用户可以只指定章节或主题范围，随后逐项提出议题，不要求预交完整议程。依据适用 AGENTS、当前接续、指定正文和必要前置资料开始；复用已知结论，不要求用户重述历史。

默认围绕用户议题正常讨论、澄清与总结；进入会议本身不自动开启 grill 或 gloss。用户可随时切换议题和分析方法；范围外内容先在聊天提出，不自行扩大正式写入范围。

## 确认结果后落文

讨论先在聊天进行。只有已确认且获准写入的结果可以进入正式正文；是否值得长期保存及具体写法按 [W05](W05-正式落文与记录.md)。本轮或阶段结果确定后即可落文，无需等待整场讨论结束。

“阶段总结”汇总结论和未决项，不自动授权写文件；“整理一下”等意图不明确时先在聊天整理。确认与写入授权可在同一句话中给出，已有明确确认和授权就执行，不增加口令或逐文件审批。用户直接指定确定改法并要求执行时，不因采用讨论或审阅模式再次询问。

## 按需保存工作材料

`工作材料/` 保存服务当前讨论、研究或执行的临时资料，例如研究经过、尚未核实的判断、候选方案、比较稿及必要原稿。它们帮助继续工作，不能作为已确认规则使用。

在已有文书任务与可写范围内，后续还需比较、核查、执行或跨聊天接续的材料，可以主动保存并告知入口。普通问答、随手推演和没有后续用途的内容留在聊天；用户要求只在聊天讨论时遵从。保存材料不自动授权正式落文。

按主题命名并复用仍在处理的文件，材料较多时再分子目录。保留任务需要的原始格式，按需说明用途、来源和未确认点；不逐轮、逐日生成，不预建空目录或套用正式正文的主题编号。

值得长期使用的确定结果经确认和授权后进入正文；仍需解决的问题按下节判断是否获准留待后续。阶段结束后的保留、归档和清理按 [W06](W06-旧文档迁移.md)，不把全部过程转存成长期文档。

## 待讨论：未决问题与待办的统一入口

`待讨论.md` 收录用户同意留待后续决定、核实或完成的事项。每库按需维护一份，已有同用途清单时复用；有获准收录的实际事项再创建。

本轮对话能完成的事项直接讨论、核查或执行，不先写入待讨论。需要用户回答的问题先在聊天提出；发现问题、暂未得到答案或仍有执行步骤，都不自动成为入单理由。

写入与维护主要由用户主动指定；Agent 认为确需保留时，先在聊天说明拟记录的具体事项及后续用途，得到用户同意后再写入。已有明确授权覆盖本次事项和维护动作时直接执行，不重复询问；超出范围的新增或修改另征同意。一般文书任务、阶段总结、归档或可写目录本身不构成清单写入授权。

- 按主题分组，每项写清需要决定的问题或要完成的动作，保留必要背景、完成条件和资料入口，让读者无需回看聊天也能明白。字段按用途取舍，不补造负责人、日期或状态。
- 以下维护动作均在用户授权范围内进行：收录获准事项、合并重复项、更新剩余工作及清理条目。候选方案比较和研究过程留在工作材料，清单只留判断或行动所需的信息。
- 已有项目任务系统时，只放必要入口，执行细节与实际状态沿用原系统，避免重复登记。正式正文不默认另建 ISSUE；已有记录在获准整理的范围内合并或改为指向唯一位置。
- 讨论已解决但尚需落文或执行时，将原问题改写为剩余待办。需要的工作全部完成并核对后移除条目；不能因已有结论或生成草稿就删除唯一提醒。
- 明确取消的事项移除；暂缓事项保留，并简短写明恢复条件。完成和取消后不在清单保存过程、结案说明或完成档案。
- 清理条目时同步受影响的当前引用和空主题；已有任务编号按项目约定维护。清空后可保留原文件与入口，不填“暂无问题”等占位。归档或版本命名不自动关闭未完成事项。

清单从总目录提供入口，首次建立时只补必要导航。动态维护清单不授权把未确认答案写入正文，也不授权执行其中的任务。见[待讨论模板](../模板/待讨论.md)。

## grill：按依赖深入追问

用户用 `grill` 或等义的明确指令开启后，在当前范围整理假设、边界、取舍和未决问题的依赖关系。每轮集中提出前置已确定的当前未决问题；依赖本轮答案的问题留待下一轮，不在未知前提上继续推演。

每个问题采用稳定编号并附建议；不重复已确认决定：

```text
❓ **Q1** — **问题标题**：需要用户决定的具体问题。

➡️ 建议选择及有助判断的具体理由。
```

可从资料核实的事实由 Agent 查证，不能把检索工作交给用户。资料或权限不足时如实说明，只暂缓受影响的判断。工作类型、资料与核验要求按项目规定，不将源码、测试作为所有文档的必读项；子 Agent 核查须有适用授权，不因开会自动派发任务。

用具体情境检查概念、例外和冲突，控制一轮问题的依赖层级。议题已解决或用户明确后移时收束；用户要求停止追问就返回普通讨论，不以无限追问阻止已明确的工作。沉默不是确认。

## 阶段结束

确认并获准落文的结果按 W05 更新正文和必要索引；待讨论清单只在上述授权范围内更新和清理。在聊天交代结果、入口及必要的未完成事项即可，不因阶段结束自动登记。按需记录见 W05，用户发起的归档或定档见 W06。
