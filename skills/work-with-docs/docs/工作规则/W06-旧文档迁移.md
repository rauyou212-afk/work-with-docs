# W06 · 迁移与归档

[文档目录](../00目录.md) · [上一词条](W05-正式落文与记录.md) · [下一词条](W07-使用与协作.md)

## 用途与范围

| 操作 | 结果 |
| --- | --- |
| 迁移 | 调整当前文档的结构或权威位置，供后续维护使用 |
| 归档 | 将退出日常使用的资料移到历史保存位置，通常不再修改，按需追溯 |
| 定档 | 标识并保存现行正文的阶段版本快照，现行正文仍留在项目中继续维护 |

归档由用户发起，按指定的阶段、主题或项目范围处理；可以与迁移、定档一起执行。范围和授权已清楚时直接完成，只澄清会影响资料取舍的缺口，不逐文件审批。启用技能或讨论方案不自动授权迁移和归档其他文档库。

新规则用于后续工作；旧记录、工作材料和过期正文只在获准整理的范围内处理。项目规定的专业记录和保留要求继续适用。

## 迁移现行文档

先定位原路径、主题编号、正文职责、权威位置和去向，按 W05 保留必要原稿。只修改旧长文的一段时保留其权威位置，不因局部改文重建全库。

获准迁移后，按 W01 拆分独立主题、建立父子目录并更新引用。普通迁移沿用已有主题编号；归档整理后的重编号按下节执行。新位置覆盖需要保留的有效内容、符合确认范围后，切换当前入口，清理失去用途的旧页面、重复索引和跳转，保持唯一可编辑正文。

术语入口迁移复用现有定义，保持一个查找入口；详细规则见 W01。原稿和历史快照与现行正文分开保存。需要后续会话沿用的新入口，只在获准修改的现有协作约定或项目入口中简短说明，不另造迁移报告或政策文件。

## 阶段归档

1. **整理有效结果和未完成事项。** 已确认、有长期使用价值的内容更新到现行正文；未完成事项先在聊天说明，清单收录和维护按 W04 的用户授权范围处理。讨论已解决但执行未完成的已收录条目，只留下剩余待办。归档不表示方案已采纳或任务已完成。
2. **按用途分流材料。** 仍需继续修改、比较或执行的材料留在 `工作材料/`；结束使用且值得追溯的材料和过期正文进入归档。议题尚未解决时，其中已经结束的研究材料也可归档，相关入口在获准维护的既有条目中同步。清除明确无用的重复件、中间产物和已被完整替代的草稿；独有的来源、依据或历史成果按用途保留。无法判断价值时先保留，只将影响取舍的问题交用户决定。
3. **使用约定归档位置。** 优先复用项目已有位置；没有约定时，使用项目内的 `归档/YYYY-MM-DD-主题/`，日期按用户时区确定。按本次范围保存资料，保留理解它们所需的目录关系、附件和来源，完成必要的链接整理。
4. **清理当前目录并重新编号。** 现行正文、未完成事项和仍在使用的工作材料留在项目中。已归档旧页退出当前主题目录，移除遗留空目录、过期目录项和无用途跳转；需要追溯时提供必要归档入口。归档后默认在本次整理范围内重新连续编排现行文档主题编号，同步文件名、标题、目录及受影响的当前引用。外部任务编号、业务标识沿用各自规则，历史归档保持当时编号和内容。确有仍在使用且无法同步更新的外部调用时，只保留其需要的兼容入口。
5. **核对受影响内容。** 确认有效结论和已登记的未完成事项有正确入口，本次移动、删除、重编号影响的当前链接可用。按 W05 核验并在聊天交代结果、入口及其余未完成事项；不默认另写归档报告、每日简记或校验清单。

归档形成后保持历史原貌，后续有效修订写入现行正文。重新研究旧材料时，将需要继续维护的部分带回工作区；既有历史归档不随日常修改或现行重编号更新。

## 按需定档

普通归档处理退出日常使用的资料；用户同时要求“定档”时，再按指定范围保存现行正文的完整版本快照，包含理解该版本必需的关联资料。现行正文继续留在项目中，快照保存到约定的历史位置。工作材料和待讨论清单保留各自用途，不自动成为版本正文。

版本号标识文档版本，不关闭未完成事项，也不代表全部实施或验收完成。默认不生成 ZIP；需要打包交付时再生成。快照完成后按历史资料保存，后续修改在现行正文中进行。
