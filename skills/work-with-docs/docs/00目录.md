# work with docs · 文档目录

版本：0.7.4

正式正文保存值得重复阅读或长期保存的确认结果与必要解释，按分层目录和独立主题组织。临时材料按用途进入 `工作材料/`；本轮能完成的事项直接处理，经用户授权留待后续的未决问题与待办由 `待讨论.md` 提供入口。写作优先保证易读易懂、层级结构、全面准确且不过度防御，再删去冗长；需要时开启 `grill` 或 `gloss`，由用户发起阶段归档。

## 工作规则

- [W01 · 文档组织与链接](工作规则/W01-文档组织与链接.md)：主题拆分、父子目录、编号、库内外链接、唯一正文与术语。
- [W02 · 按需读取与上下文](工作规则/W02-按需读取与上下文.md)：复用已读资料、局部读写与任务接续。
- [W03 · 文档审阅](工作规则/W03-文档审阅.md)：处理批注、确认结果与关联修订。
- [W04 · 会议与阶段总结](工作规则/W04-会议与阶段总结.md)：讨论、grill、工作材料、待讨论与待办。
- [W05 · 正式落文与记录](工作规则/W05-正式落文与记录.md)：正文准入、恢复原稿、核验与按需结果记录。
- [W06 · 迁移与归档](工作规则/W06-旧文档迁移.md)：权威切换、阶段归档、目录清理与重编号、按需定档。
- [W07 · 使用与协作](工作规则/W07-使用与协作.md)：操作示例、阅读、安装与技能分工。
- [W08 · 写作与表达](工作规则/W08-写作与表达.md)：概览首段摘要与有效索引、具体表达及阅读连贯；新写、改写或审阅表达时读取。

## 按需模板

- [目录页](模板/目录页.md)
- [父主题概览](模板/父主题概览.md)：首段摘要与链接示例、后文说明及子目录。
- [独立词条](模板/独立词条.md)
- [待讨论清单](模板/待讨论.md)：经用户授权收录和维护后续事项，每库按需一份，完成后移除。
- [按需结果简记](模板/会议接续.md)：用户需要回顾记录或项目有记录要求时使用。
- [审阅交接提示](模板/审阅交接.md)：明确需要额外交接时使用。
